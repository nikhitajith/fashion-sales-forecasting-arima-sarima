# fashion-sales-forecasting-arima-sarima
Forecasting daily fashion e-commerce revenue on the Olist Brazilian dataset with ARIMA and SARIMA. Covers ADF stationarity testing, ACF/PACF order selection and weekly seasonal decomposition. SARIMA(1,0,1)(1,0,1,7) beats ARIMA on a 30-day test set (RMSE 160.21, 61.3% WMAPE accuracy).
